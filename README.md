## 🚀 Getting Started

### Prerequisites

Make sure Dart SDK is installed on your system.

Download Dart SDK:
https://dart.dev/get-dart

Verify installation:

```bash
dart --version
```

### Clone the Repository

```bash
git clone https://github.com/Nasim-hub24/Introduction-to-DART.git
```

Navigate into the directory:

```bash
cd Introduction-to-DART
```

Run a Dart file:

```bash
dart run filename.dart
```
